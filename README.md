Projeto final da Fase 2 do meu curso de Fundamentos de Sistemas Web na PUCRS.

O website é uma simulação de um mercado online que possui sistema de compras, delivery e cadastro.

As evoluções comparando com a Fase 1 do projeto, foram a utilização do Bootstrap para a customização do site e melhor organização do mesmo e um sistema de cadastro para conta e delivery funcional.
Também adicionei mais produtos e um botão que simula o ato de adicionar eles ao carrinho, no menu adicionei um banner rotativo que serve para simular as promoções que geralmente esses tipos de site possuem.
